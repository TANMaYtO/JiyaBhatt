# Jiyaa Bhatt — Writing Portfolio

A responsive, static portfolio site for a technical/content writer. Built with plain HTML, CSS, JavaScript, and local artwork. No build system, API key, or paid service is required.

## Preview locally

1. Download and extract this folder.
2. Open `index.html` in a browser, or serve the folder with any static server. For example:
   - Python: `python -m http.server 8000`
   - Then open `http://localhost:8000`
3. The Google Fonts import is progressive enhancement; the page uses system fallbacks if it cannot load.

## Deploy

Upload this folder to a static host such as Vercel, Netlify, GitHub Pages, or any ordinary web server. No build command is needed.

## Status & Local Server

The website is production-ready and currently being served locally at:
`http://localhost:8080` (port 3000 left completely untouched).
